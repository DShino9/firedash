決定事項は [要件.md](要件.md)（番号付き）。全体図は DS9i vault の

## 操作

| したいこと | リモコン | 指 |
|---|---|---|
| 枠をえらぶ | 十字 | — |
| 窓の中に入る／出る | 決定 ／ 戻る | 枠を押す |
| 窓を替える | **W** | 枠の見出しの「替える ▾」 |
| 大きく（一時的に1枚） | **F**（戻るで解除） | — |
| かたちを変える | **1〜5** | 上の帯 |
| 設定 | 上の帯へ十字で上がって決定 | ⚙ 設定 |

## 窓の足しかた

`panels/` に1ファイル増やし、`app.js` の `PANELS` に足すだけ。窓は次の形。

```js
export default {
  id:'...', name:'...', icon:'🙂', hint:'窓えらびに出る一行',
  create(ctx){                    // ctx = { note, cfg, save }
    return {
      el,                         // 必須。枠の中に入る要素
      tick(){},                   // 任意。1秒ごと
      resize(){},                 // 任意。枠の大きさが変わったとき
      onKey(e){ return false; },  // 任意。true を返すと盤に渡さない
      enter(){}, leave(){},       // 任意。中に入った／出た
      refresh(){}                 // 任意。設定が変わった
    };
  }
};
```

## カレンダーの窓

**壁掛けカレンダーの月表示**と**週表示**。祝日は holidays-jp（鍵不要・CORS 可）から
年に1回だけ取り、端末に30日控える。日曜と祝日は赤、土曜は青。今日は枠ごと明るくする。

| キー | |
|---|---|
| 左右 | 前後（月表示なら前月／週表示なら前週） |
| 決定 | 月⇄週 |
| T | 今日へ |
| 上下 | 盤へもどる |

3分さわらなければ今日の月へ戻る（壁に掛ける画面なので）。
枠が低いときは予定を点だけにする。**中身はまだ仮**（要件 5）。

## YouTube の窓（BGM の棚）

`playlists.json` に並べたプレイリストを出し、押すと枠の中で流れ続ける。
動かすのは postMessage だけ（`iframe_api` を読まないので、外の script が落ちても棚は死なない）。
9秒返事が無ければ「弾かれた」とみなし、公式アプリへ渡す札を出す。

| キー | 流している間 |
|---|---|
| 決定 | とめる／ながす |
| 左右 | 曲送り |
| M | 消音の入り切り（端末に覚える） |
| 戻る | 棚にもどる（もう一度で枠から出る） |

**枠から出ても、かたちを変えても鳴り続ける。** そのために盤は枠を DOM から動かさず、
grid の行と列だけ書き換える（動かすと iframe が読み直されて鳴り止む。実測で確認）。

## 守ること

- **`?.` と `??` を書かない。** Fire OS の WebView は版が古いことがある
- 端末に残す控えは `firedash-` 接頭辞だけ（Cache Storage はオリジン共有）
- 焦点の移動は「帯が重なっているものを優先」。中心の距離だけで測ると右を押して上へ飛ぶ
- 遠くから見る画面。焦点の枠は常に見えること
